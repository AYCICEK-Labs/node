# node

The Node.js version of AYÇİÇEK Labs: the active LTS line, **Node 26**.

| File     | Purpose                                                                                                  |
| -------- | -------------------------------------------------------------------------------------------------------- |
| `.nvmrc` | The major version only, so every project gets the latest Node 26 release with `nvm install` / `nvm use`. |

## Use it in a project

```sh
curl -fsSL https://raw.githubusercontent.com/AYCICEK-Labs/node/main/.nvmrc -o .nvmrc
nvm install
```
